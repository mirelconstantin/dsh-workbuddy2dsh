Upkeep tasks cover disabled accounts
Disabling only stops selection: when on, disabled accounts still check in / report activity / keep alive / refresh balance (they still don't take part in selection). Suits the rotation-farming pattern of "open one account at a time and use disable as a traffic switch"; off by default.
If you only want a single account to temporarily leave selection while keeping upkeep, use the account row's "Pause selection" button (account-level, no need to enable this switch).
